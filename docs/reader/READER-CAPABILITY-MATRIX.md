## Capability Status Definitions

- **RUNTIME-PROVEN**: Validated through complete end-to-end user workflows, automated desktop vitest test suites, Rust workspace integration tests, and production build pipelines.
- **FRONTEND-VERIFIED**: Component mounted, state wired, UI events bound, and verified with React Testing Library / Vitest in pps/desktop.
- **INTEGRATION-TESTED**: Backed by full-stack Rust test suites (	est_reader_formats_integration.rs, 	est_runtime_acceptance_matrix.rs, 	est_canonical_reader_service.rs) and storage repositories.
- **UNIT-TESTED**: Covered by low-level crate test fixtures in luma-reader, luma-core, and luma-storage.
